# 项目网站统一视觉预览

直接打开 `index.html`，或在工作区运行 `python -m http.server 8765 --bind 127.0.0.1` 后访问 `http://127.0.0.1:8765/optimized-site/`。

- 六个页面使用统一样式，不修改 example-site；导航均在 optimized-site 内跳转。
- 本轮沿用参考站项目名称、正文、图示、日期及联系信息，仅供确认视觉效果，尚未替换为本项目内容。
- 页眉替换 NSFC 标志，取消旋转；页尾移除栏目导航。
- index.html：项目概况、研究路线图、正文、时间轴。
- news.html：独立新闻列表。
- team.html：承担单位、承研人员，保留完整介绍与个人主页链接。
- innovation.html：传输架构、拥塞检测、拥塞控制、应用示范，保留 12 项创新成果。
- materials.html：34 条带序号、悬挂缩进的 reference，分列论文、专利、标准、人才培养。引用仅使用原站已有题名、会议/期刊、年份等字段，没有补造作者、卷期或 DOI；原有文档链接继续保留。
- prototype.html：系统拓扑、19 个可切换节点、11 张实验与应用验证表格。流量曲线仅为静态交互示意，不接实时数据源；济南以外的缺失节点照片省略。
- 参考首页一条新闻图片缺失，本预览保留文字并省略该图片。
- assets 为预览本地资源。`build_preview.py` 是一次性提取脚本，浏览网页不需要 Python 或其他依赖。

设计取向：深蓝、蓝灰底色、细线网格、编号章节，正文优先。中文使用系统字体，不加载远程字体与组件库。

验证：六页在 375px、768px、1280px 下没有页面横向溢出；本地链接、锚点、图片检查通过。宽数据表可在独立容器内横向滚动，并支持键盘聚焦。拓扑选择可通过下拉框或点击图中节点操作。

版本管理：Git 仓库位于 optimized-site，分支为 preview-ui；保留修改前基线和后续优化提交。

源码排版：HTML、CSS、JavaScript 使用两空格缩进，格式规则见 `.prettierrc.json` 和 `.editorconfig`。支持 Prettier 的编辑器可以直接使用该配置。生成脚本输出的 HTML 同样保留缩进与换行；手动修改页面后无需执行生成脚本，运行它会覆盖页面内容。

首页时间轴：绿色为已完成，蓝色为当前，灰色为未完成；页面不显示阶段状态文字。预览按现有时间表将中期检查设为当前节点，实际完成情况尚需随本项目内容一起核对。状态同时通过无障碍属性提供给读屏软件。
