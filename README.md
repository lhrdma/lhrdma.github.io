# 负载感知的广域 RDMA 路由选择技术

面向未来智算网络应用对超高吞吐、超低时延广域传输的需求，本项目聚焦广域 RDMA 网络，研究负载感知的路由选择技术。针对传统 RDMA 网络广域传输效率受限、负载均衡能力不足、拥塞时性能急剧下降，以及流量调度对应用流量模式考虑不足、难以应对突发流量等问题，研究快速准确的负载检测方法和负载感知的路由决策算法，旨在提高多种流量模式下广域 RDMA 网络的整体吞吐率，缩短流完成时间，降低尾延时。

本仓库为项目展示网站源码，包含项目概况、项目进展、项目团队、创新成果、资料汇编和原型系统六个栏目。

## 网站结构

| --- | --- |

| `main.js`、`news.js`、`prototype.js` | 导航、项目进展图片预览与原型系统交互 |
